# Site de Isabelly Roditis — publicação pelo GitHub

Os arquivos deste diretório já estão compilados. Para publicar:

1. No GitHub, crie um repositório vazio e escolha **Add file → Upload files**.
2. Envie **o conteúdo desta pasta**: `index.html`, `vercel.json`, `favicon.svg`, `asset-manifest.json`, `images/`, `static/` e este README. Eles devem aparecer diretamente na raiz do repositório.
3. Importe o repositório na Vercel. Se for atualizar um projeto existente, confira em **Settings → Build and Deployment**: **Root Directory** vazio (raiz do repositório), **Framework Preset** Other, **Build Command** vazio e **Output Directory** `.`. Faça um novo deploy após o commit.

Se recebeu um ZIP, **extraia antes de enviar ao GitHub**. Enviar apenas o arquivo `.zip` não publica o site.
